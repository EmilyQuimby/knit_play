Note: JDK (Java) 13 is required to run this program

Open terminal/command-line and navigate to the directory containing
PlayAKnit.jar, and execute the following command:

java -jar KnitPlay.jar


Unit test can be run from Eclipse IDE. Open the project in Eclipse and add JUnit-5 to the libraries by right-clicking in the project folder --> Build Path --> Add Libraries... --> select "JUnit" --> make sure version 5 is selected --> Finish

Run the Unit test KnitGraphTest.java
